# 我的白板 v1.0.0

首个正式版本：一个基于 **PySide6 / Qt Graphics View** 的 Windows 桌面白板，
免安装、配置写在程序目录里（便携模式）。

## 下载

| 文件 | 说明 |
|------|------|
| `Whiteboard-1.0.0-win64.zip` | 免安装便携版。解压到任意可写目录，双击 `Whiteboard.exe` 即可（无需安装 Python）|

系统要求：Windows 10 / 11 64 位。

> 解压后如果 `Whiteboard.exe` 所在目录不可写（例如放在 `Program Files`），
> 配置会自动改存到系统的应用数据目录，启动时状态栏会提示实际位置；
> 也可以用 `Whiteboard.exe --paths` 查看。

## 本版功能

- **画笔**：自由手绘，中点二次贝塞尔平滑，采样阈值按屏幕像素计算
- **橡皮擦**：擦断笔迹 —— 擦中间断成两段、擦两端变短、全覆盖才消失；
  光标处显示作用范围圆圈，大小随「粗细」滑块变化
- **形状**：矩形 / 椭圆 / 直线 / 箭头，拖拽实时预览
- **文字**：点击落点输入，选择工具双击可再编辑
- **选择 / 移动**：点选、`Ctrl` 多选、空白处拖拽框选、拖动整体移动
- **拖动画布**：工具栏「拖动」工具（四向箭头），也支持空格+左键、中键拖拽
- **多页面**：每页独立场景 + **独立撤销栈**（在第 2 页撤销不会改动第 1 页）
- **撤销 / 重做**：一次橡皮拖拽、一次批量删除都只算一步
- **文档**：`.wbd`（UTF-8 JSON，可读可手改，原子写入）；导出 PNG；导入图片
- **自动保存**：默认每 60 秒写入 `autosave.wbd`，异常退出后可恢复
- **主题**：浅色 / 深色一键切换

## 快捷键

| 操作 | 快捷键 |
|------|--------|
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）|
| 新建 / 打开 / 保存 / 另存为 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 导出 PNG / 导入图片 | `Ctrl+E` / `Ctrl+I` |
| 新建页面 / 删除当前页 | `Ctrl+T` / `Ctrl+Shift+D` |
| 上一页 / 下一页 | `PgUp` / `PgDn` |
| 适应窗口 / 实际大小 | `Ctrl+0` / `Ctrl+1` |
| 删除选中 / 清空当前页 | `Delete` / `Ctrl+Shift+Backspace` |
| 平移画布 | 空格+左键拖拽，或中键拖拽，或「拖动」工具 |

## 便携与清理

配置与自动备份都在程序目录（**不写注册表**）：

```
Whiteboard.exe
whiteboard.ini      ← 颜色 / 粗细 / 当前工具 / 主题 / 窗口位置
autosave.wbd        ← 自动备份
```

卸载 = 删除整个文件夹。从旧版本升级过来的话，首次运行会把注册表里的旧偏好
自动迁移到 `whiteboard.ini` 并清掉旧键。
